AUTO-CLIPPER v1 - INSTALAÇÃO (Windows)
=======================================

1) Python 3.10 a 3.12 (o TensorFlow ainda pode não suportar versões mais novas)

2) ffmpeg (no cmd):
     winget install Gyan.FFmpeg
   Feche e abra o cmd de novo depois.

3) Bibliotecas (dentro da pasta do projeto):
     pip install -r requirements.txt

4) Google Drive para desktop instalado e logado.
   Confira a letra do Drive (normalmente G:\Meu Drive) e ajuste PASTA_CLIPES no config.py.

5) Coloque os links em LINKS_DAS_LIVES no config.py e rode:
     python main.py

   Ctrl+C para parar.
   Clipes: PASTA_CLIPES\<canal>\<canal>_<data>_<motivo>.mp4
   Log: autoclipper.log  |  erros de captura: buffer\<canal>_captura.log

AJUSTE FINO (config.py)
- Muito clipe ruim  -> aumente LIMIAR_SCORE (ex.: 0.65)
- Pouco clipe       -> diminua LIMIAR_SCORE (ex.: 0.45)
